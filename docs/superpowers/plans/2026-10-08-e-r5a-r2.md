# E + R5a + R2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Same-script render-only A/Bs with lean answers (E), a dual-mono
loudness fix and a bounded bed swell (R5a), and F5 breath-group chunking
with per-chunk Whisper QA and best-of-3 re-render (R2). Every golden-path
change is behind a default-OFF flag.

**Architecture:**
- **E** extracts `render_script()` from `auto_generate.run()`. It adds a
  `--scripts-from` mode to `scripts/eval_genres.py`, and an env fingerprint
  to the TTS cache key so flag arms never reuse the wrong voice.
- **R5a** lives in `core/mixer.py` and `core/pipeline.py`.
- **R2** adds `core/f5_tts/chunking.py` (pure) and `core/speech_qa.py`
  (engine-agnostic), wired into `F5Engine.synthesize` behind flags.

**Tech Stack:** Python 3.11, numpy, scipy, pyloudnorm, pedalboard, f5-tts
1.1.22, transformers Whisper (`core.eval.speech_metrics`), pytest/unittest.

**Spec:** `docs/superpowers/specs/2026-10-08-e-r5a-r2-design.md`

## Global Constraints

- **Commits:** commit to `dev` and never push. Use conventional commits
  ending with `Co-Authored-By: <your model> <noreply@anthropic.com>`.
- **Tests:** `.venv/bin/python -m pytest tests/unit/ -q` must stay green
  (853 at start). Unit tests never load real models.
- **Real models:** any step that loads one (F5, Whisper, Ollama) holds
  `var/heavy-model.lock`:
  - acquire with `mkdir var/heavy-model.lock`, then write an `owner` file;
  - wait in bounded polls;
  - release with `rm -rf var/heavy-model.lock`.

  Only the controller runs such steps (Tasks 9 and 15).
- **Flags:** new golden-path flags default OFF:
  - `MOODSCAPE_BED_RISE_LIMIT`, `MOODSCAPE_F5_CHUNKING`,
    `MOODSCAPE_F5_CHUNK_QA` default `0`;
  - `MOODSCAPE_BED_SPEECH_OFFSET_LU` / `MOODSCAPE_BED_PAUSE_OFFSET_LU` are
    unset by default;
  - `MOODSCAPE_LOUDNESS_DUAL_MONO` defaults to `1` (bug fix, kill-switch).
- **Flags off means byte-identical:** with every new flag OFF/unset, mixer
  and F5 output must match today's exactly. The one intended exception is
  the loudness fix, which can be disabled with
  `MOODSCAPE_LOUDNESS_DUAL_MONO=0`.
- **Invariants:** no pedalboard `Limiter`. Keep `<problems>` stripping,
  writer/judge independence, `unload()` after LLM stages, and the
  FATAL/ADVISORY split. Imports use the form `from core.x import Y`.

```python
import os
from collections.abc import Mapping

_TTS_ENV_PREFIXES = ("MOODSCAPE_F5_", "MOODSCAPE_CHATTERBOX_")


def tts_env_fingerprint(environ: Mapping[str, str] | None = None) -> str:
    """Stable string of every set TTS-affecting env var, so flag arms never share a cache entry."""
    env = os.environ if environ is None else environ
    items = sorted((k, v) for k, v in env.items() if k.startswith(_TTS_ENV_PREFIXES))
    return ";".join(f"{k}={v}" for k, v in items)
```

**Behaviour:**
- **Order:** collect all `(case, pos, arms...)` entries first, then
  `rng.shuffle(entries)`, then assign ids `00..`. Use the same `rng`, seeded
  from `seed`.
- **Positions:** `positions` filters `POSITIONS` by name, and an unknown

  count as **ties** for the verdict and for `ties`.
- **Extra statistics:**
  - `weighted_rate = (cw + 0.5*cl) / (cw + bw + 0.5*(cl + bl))`, or 0.0
    when the denominator is 0;
  - `lean_inclusive_p = sign_test_p(cw + cl, cw + bw + cl + bl)`.
- **`by_position` buckets** gain `challenger_leans` / `baseline_leans`.
- **The error message** for an invalid choice lists
  `A, B, leanA, leanB or same`.
- **`ab_export.py --positions start,middle`.**
- **`ab_score.py`** prints a second line:
  `Leans: challenger X / baseline Y; weighted rate R; lean-inclusive p P (reported only)`.

```python
def _slew_limit_rise(g_db: np.ndarray, sample_rate: int, db_per_sec: float, control_hz: float = 100.0) -> np.ndarray:
    """Limit how fast the gain may RISE (falls pass through). Runs at a control rate, then interpolates."""
    n = g_db.shape[0]
    if n == 0 or db_per_sec <= 0:
        return g_db
    step = max(1, int(sample_rate / control_hz))
    ctrl = g_db[::step].astype(np.float64)
    max_up = db_per_sec / control_hz * (step * control_hz / sample_rate)
    out = np.empty_like(ctrl)
    out[0] = ctrl[0]
    for i in range(1, ctrl.size):
        prev = out[i - 1]
        out[i] = ctrl[i] if ctrl[i] <= prev else min(ctrl[i], prev + max_up)
    x_ctrl = np.arange(ctrl.size) * step
    return np.interp(np.arange(n), x_ctrl, out).astype(np.float32)
```

### Task 10: Breath-group chunker (pure)

**Files:**
- Create: `core/f5_tts/chunking.py`
- Test: `tests/unit/test_f5_chunking.py`

**Interfaces:**

```python
SAFETY = 0.9

@dataclass(frozen=True)
class BreathGroup:
    text: str
    gap_after_sec: float | None   # None = last group of the segment (caller keeps today's join)

def f5_char_budget(ref_text: str, ref_duration_sec: float, speed: float) -> int
    # int(len(ref_text.encode("utf-8")) / ref_dur * (22 - ref_dur) * speed * SAFETY), minimum 20
def gap_for(text: str, environ=None) -> float
    # final punctuation (ignoring closing quotes/brackets): .!?… -> MOODSCAPE_F5_GAP_SENTENCE (0.45);
    # ;: -> _CLAUSE (0.35); , — – -> _COMMA (0.20); else 0.0
def breath_groups(text: str, budget: int, environ=None) -> list[BreathGroup]
```

**Algorithm:**
1. Tokenise `text` into units that end at a sentence end, at `; :`, at
   `,`, or at an em/en-dash followed by whitespace. Use a single regex
   split that keeps the delimiter with the left unit.
2. Greedily pack units while
   `len((cur + " " + unit).encode("utf-8")) <= budget`.
3. A single unit over the budget is split at the last space before the
   budget, repeatedly. A unit with no space is emitted whole: never loop,
   never drop text.
4. Each group's `gap_after_sec = gap_for(group.text)`, except the last,
   which gets `None`.
